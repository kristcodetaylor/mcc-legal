Ce que disent les clés des songes

Se cacher est lu comme le fait de protéger quelque chose — toi-même, un secret, un sentiment. Les clés des songes demandent ce que tu préférerais qu’on ne trouve pas.

« Se cacher » n’est qu’un symbole de ton rêve. Note le rêve en entier dans My Cosmic Code : l’app repère les symboles qu’il contient et, avec le temps, te montre lesquels reviennent. Le journal de rêves est gratuit et reste sur ton téléphone.
