My Cosmic Code

合盘计算：用两张完整的本命盘看星座配对

太阳星座配对只比较两个星座。My Cosmic Code 比较两张完整的本命盘，把一个人的每颗行星与另一个人的每颗行星逐一对照，显示两者在哪些地方交汇。

比较哪些方面

  • 五个生活领域：爱情、亲密关系、友情、工作和身心健康。
  • 两张星盘之间的相位（合盘）。
  • 组合盘。
  • 宫位叠加：一个人的行星落在另一个人星盘的哪个宫位。

不打分，也没有百分比

应用不会把两个人简化成一个数字。你看到的是两张星盘实际如何交汇，是否合适由你自己判断。

从设计上保护隐私

无广告、无数据分析、无追踪器、无需账号。你的出生信息、星盘和日记只保存在你的设备上，你可以在应用内导出或删除。

常见问题

什么是合盘（比较盘）？

通过一个人的行星与另一个人的行星之间的相位，来比较两张本命盘。

需要双方的出生时间吗？

星座以及行星之间的相位只需出生日期就能计算。上升星座和宫位叠加则需要双方准确的出生时间和地点。
