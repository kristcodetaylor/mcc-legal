本命盘：你的太阳、月亮和上升星座

本命盘（出生星盘）是你出生那一分钟、在出生地点所见的星空图。My Cosmic Code 在你的手机上依据真实天文数据计算，并绘制完整的星盘图，而不只是告诉你一个星座。

本命盘会显示什么

  • 你的太阳星座、月亮星座和上升星座：星盘解读时要一起看的三个星座。
  • 每颗行星所在的星座和宫位，并标出逆行的行星。
  • 行星之间的相位及其容许度。
  • 在完整的本命盘图上标出上升点和天顶。
  • Cosmic Report 把你的星盘和数字汇集在一处，涵盖全部 144 种太阳与上升星座组合的文字解读。

你需要准备什么

你的出生日期、出生时间和出生地点。上升星座和宫位取决于确切的时间和地点：上升点大约一天走完全部十二个星座，约每两小时换一个星座。

从设计上保护隐私

无广告、无数据分析、无追踪器、无需账号。你的出生信息、星盘和日记只保存在你的设备上，你可以在应用内导出或删除。

常见问题

如何查询我的上升星座？

输入你的出生日期、准确的出生时间和出生地点。上升星座是那一刻正从东方地平线升起的星座，所以除了日期，还需要时间和地点。

太阳星座和本命盘有什么区别？

太阳星座只是星盘中的一个落点：你出生时太阳所在的星座。本命盘标出每颗行星、月亮、上升点和十二宫的位置，并显示它们之间的相位。
