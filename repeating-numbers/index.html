How numerology reads a number

Every digit is added, and the total is added again until one digit is left: 1+1+1+1 = 4. That digit, 1 to 9, is the core of the reading. Some numbers are kept as they are: 11, 22 and 33 are master numbers, and 13, 14, 16 and 19 are called karmic-debt numbers. A number that reads the same both ways is a mirror, and a time like 12:12 repeats one group. Each of these adds a layer to the reading. You can check every sum on paper.
