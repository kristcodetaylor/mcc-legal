今日のカード：デッキ全体から、今日の一枚

今日の流れを見る一枚。それが My Cosmic Code のデッキにある「今日のカード」です。ここですぐに引けます。デッキはブラウザの中で混ぜられ、アプリがスマホで混ぜるのと同じ方法です。

今日のカード：一枚引く

78枚のデッキ全体から、今日の一枚を引きます。カード名、逆位置かどうか、キーワード、テーマ、そしてじっくり考えたい問いを、アプリと同じように表示します。

Google Play で手に入れよう

表示される内容

  • カード名：愚者（0）から世界（21）までの22枚のうちの1枚、またはワンド・カップ・ソード・ペンタクルの4つのスートの56枚のうちの1枚。
  • 正位置か逆位置か。逆位置のカードはオフにできます。
  • 3つのキーワード。カードが逆位置のときは変わります。
  • カードのテーマと、じっくり考えたい問い。

カードの引き方

78枚すべてを混ぜて、1枚を取ります。カードは文章が表示される前に決まり、文章がカードを変えることはありません。表示されるのは、いつもそのカードのために書かれた言葉です。逆位置を含める場合は、コイントスでカードの向きが決まります。

デッキでできること

  • クイック・インサイト：気になっていることについての一枚。問いを添えることもできます。
  • 3枚のリーディング：過去 / 現在 / 未来、状況 / 課題 / 導き、恋愛と人間関係、仕事と創造の道、決断：選択肢A と 選択肢B。
  • シャドウ・リーディングと、10枚のケルト十字。
  • 読み解きを保存して、あとでもう一度開けます。

プライバシーを守る設計

広告なし、アクセス解析なし、トラッカーなし、アカウント登録不要。出生情報、チャート、日記はお使いの端末にのみ保存され、アプリ内でエクスポートや削除ができます。このページのカードはブラウザの中で引かれ、何も送信・保存されません。

よくある質問

今日のカードはランダムですか？

はい。引くたびにデッキ全体を混ぜ直します。ここでもアプリでも同じです。あなたに関する情報は引き方に一切使われません。

逆位置のカードとは？

上下逆さまに出たカードのことで、正位置のキーワードの代わりに逆位置のキーワードが表示されます。「逆位置のカードを含める」をオフにすると、どのカードも正位置で出ます。

カードは今日何が起こるかを教えてくれますか？

いいえ。キーワードとテーマ、考えるための問いを示すだけで、可能性のあるテーマであり、予測ではありません。あなたの一日をかたちづくるのは、あなたの選択と状況です。

カードは何語で読めますか？

アプリの13言語すべてです。カード名、キーワード、問いはそれぞれの言語で書かれています。
