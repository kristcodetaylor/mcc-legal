月星座・太陽星座を生年月日で調べる

あなたの星座とは、生まれたときに太陽があったサインのことです。一年のほとんどは日付だけで決まりますが、太陽が次のサインへ移る日はそうはいきません。月は二〜三日ごとにサインを変えます。私たちは一日全体を確かめ、出生時刻で決まる場合はそうお伝えします。

私の星座は？太陽星座・月星座の計算

生年月日を入力すると、あなたの星座（太陽星座）と月星座を、それぞれのエレメントと区分と一緒に表示します。出生時刻がわかれば入力してください。その日に太陽や月がサインを移動した場合は、時刻で決まります。

計算でわかること

  • あなたの星座：生年月日に太陽があったサイン。
  • あなたの月星座：月があったサイン。
  • それぞれのサインのエレメント（火・地・風・水）と区分（活動宮・不動宮・柔軟宮）。
  • その日に太陽や月がサインを移動した場合：両方のサインと、出生時刻で決まるという注記。

日付だけでは足りない場合がある理由

太陽は毎月20日前後（数日の幅があります）に新しいサインへ入り、その時刻は毎年違います。そのため雑誌に載っている星座の日付はあくまで目安です。月はずっと速く動き、ほぼ二日に一度は新しいサインに入ります。出生時刻がない場合は一日全体を確かめ、始めから終わりまで同じサインだったときだけ表示します。時刻と都市があれば、その都市のタイムゾーン（サマータイムも含む）で正確な瞬間を計算します。

アセンダントと出生図のほかの部分

アセンダント（上昇宮）はおよそ二時間ごとに変わるため、正確な出生時刻と出生地が必要です。My Cosmic Code はアプリの中でそれを計算し、各天体のサインとハウス、天体どうしのアスペクト、出生図のホイール全体も表示します。

よくある質問

私の星座は何ですか？

生まれたときに太陽があったサインで、太陽星座とも呼ばれます。上に生年月日を入力してください。太陽がサインを移動した日に生まれた場合は、出生時刻も入力してください。

星座の境目に生まれました。どちらの星座ですか？

どちらか一方で、両方ということはありません。生まれたその一分に、太陽はまだ前のサインにいたか、すでに次のサインに入っていたかのどちらかです。境目の時刻は年によって最大一日ずれるため、出生時刻で決まります。

私の月星座は何ですか？

生まれたときに月があったサインです。月は二〜三日ごとにサインを変えるので、多くの日付では出生時刻がないと確定できません。

エレメントと区分とは何ですか？

十二のサインを分ける二つの方法です。どのサインも四つのエレメント（火・地・風・水）のひとつと、三つの区分（活動宮・不動宮・柔軟宮）のひとつを持ちます。たとえば牡羊座は活動宮の火のサインです。

これはインド占星術の星座ですか？

いいえ。これは季節を基準にした西洋（トロピカル）の黄道十二宮です。インド占星術は恒星を基準にし、約24度ずれているため、インド占星術での星座はひとつ前になることがよくあります。アプリのホロスコープでは、ヴェーダの月星座も確認できます。
