My Cosmic Code

ホロスコープ作成：あなたの太陽星座・月星座・アセンダント

出生図（ネイタルチャート）は、あなたが生まれた瞬間に、その場所から見えた空の地図です。My Cosmic Codeは実際の天文計算にもとづいてスマートフォン上で出生図を計算し、生まれ星座だけでなく、チャート全体を描き出します。

出生図（ホロスコープ）計算

生年月日を入力し、わかれば出生時刻と都市も入れると、太陽・月・惑星がどこにあったかを表示します。それぞれのサインと度数を、黄道の円の上に。

出生図でわかること

  • 太陽星座、月星座、アセンダント（上昇星座）。占星術ではこの3つを合わせて読みます。
  • 各天体の星座とハウス。逆行中の天体も表示。
  • 天体どうしのアスペクトとオーブ。
  • 円形のネイタルチャートに描かれたアセンダントとMC（天頂）。
  • 「Cosmic Report」：チャートと数字をひとつにまとめたレポート。太陽星座とアセンダントの全144通りの組み合わせそれぞれに解説文があります。

必要なもの

生年月日、出生時刻、出生地の3つです。アセンダントとハウスは、正確な時刻と場所によって決まります。アセンダントは約1日で12星座をひと巡りし、おおよそ2時間ごとに次の星座へ移ります。

プライバシーを守る設計

広告なし、アクセス解析なし、トラッカーなし、アカウント登録不要。出生情報、チャート、日記はお使いの端末にのみ保存され、アプリ内でエクスポートや削除ができます。

よくある質問

アセンダント（上昇星座）はどうやって調べればいいですか？

生年月日、正確な出生時刻、出生地を入力してください。アセンダントはその瞬間に東の地平線から昇ってくる星座なので、日付だけでなく時刻と場所が必要です。

太陽星座と出生図の違いは何ですか？

太陽星座は、太陽がどこにあったかを示すひとつの配置です。出生図には、すべての天体、月、アセンダント、12のハウスが配置され、それらの間のアスペクトも示されます。

無料ですか？

アプリは無料でダウンロードでき、現在のバージョンではすべての機能が使えます。広告はありません。
