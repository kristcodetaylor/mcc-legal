今日の惑星：月と惑星はいまどこにある？

惑星は動き続けています。月は2〜3日ごとに星座を移り、水星は年に3回ほど逆行します。このページは、My Cosmic Code アプリがスマホで使っているのと同じ天文計算で、いまこの瞬間の空をブラウザの中で計算します。

今日の惑星：星座・月相・逆行

太陽・月・惑星がいまどこにあるかを表示します。月の満ち欠けと月星座、各惑星の星座と度数、逆行中の惑星、そしてこれからの7日間の変化です。

この計算ツールでわかること

  • 月の満ち欠け、輝いている割合、月の星座と度数、そして次の星座に移る日時。
  • 太陽・月・8つの惑星、それぞれの星座と度数。
  • いま逆行中の惑星：地球から見て、見かけの動きが後ろ向きになっている惑星です。
  • これからの7日間：新月・満月・上弦・下弦、星座を移る惑星、逆行や順行に転じる惑星。

水星はいま逆行中？

逆行の行を見てください。水星が ℞ つきで載っていれば、いま逆行中です。地球から見て、惑星がしばらく黄道を後戻りしているように見えるのが逆行です。実際に向きを変えるわけではなく、地球とその惑星が違う速さで動いているために起こる見かけの動きです。向きが変わる日は「留」と呼ばれ、7日間のリストに表示されます。

アプリでは

  • 天体：同じ空に加えて、今日の惑星どうしのアスペクトと、好きな日の空を1日ずつ。
  • コズミック・ライブ：今日の空があなた自身の出生図のどこに触れているか。月とパーソナルデイも一緒に。
  • コズミック・タイムライン：あなたのチャートにこれから訪れる、日付つきのできごと。
  • トランジットのお知らせ：惑星の逆行・順行への転換、新月や満月、惑星があなたの星座に入る日・出る日は必ずお知らせ。

よくある質問

今日の月星座は？

計算ツールのいちばん上に、度数と次の星座に入る時刻と一緒に表示します。月は2〜3日ごとに星座を移るので、1日のうちに答えが変わることもあります。

いま逆行している惑星は？

計算ツールに一覧で表示します。水星は年に3回ほど、それぞれ3週間ほど逆行します。金星と火星はそれより少なく、木星から冥王星は毎年数か月ずつ逆行します。太陽と月が逆行することはありません。

時刻はどのタイムゾーン？

ブラウザのタイムゾーンです。都市を選ぶと、その都市の時刻で表示します。惑星の位置は地球上のどこでも同じで、変わるのは時計の時刻だけです。

どれくらい正確？

位置は実際の天文計算によるもので、誤差は角度の1分未満です。月相と星座の移動は分単位、留は日単位で表示します。留の前後では惑星がほとんど止まって見えるためです。

何かが送信されますか？

いいえ。すべてブラウザの中で計算し、保存も送信もしません。アプリもスマホの中で同じように動きます。
