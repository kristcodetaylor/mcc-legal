My Cosmic Code

合盤計算：用兩張完整本命盤看星座配對

太陽星座配對只比較兩個星座。My Cosmic Code 比較兩張完整的本命盤，把一個人的每顆行星和另一人的每顆行星逐一對照，並顯示它們在哪裡交會。

在 Google Play 下載

你可以比較什麼

  • 五個生活領域：愛情、親密關係、友情、工作與身心狀態。
  • 兩張星盤之間的相位（比較盤）。
  • 組合盤。
  • 宮位疊加：一個人的行星落在另一人星盤的哪個宮位。

沒有分數，也沒有百分比

應用程式不會把兩個人簡化成一個數字。你會看到兩張星盤實際如何交會，合不合適由你自己判斷。

隱私優先的設計

沒有廣告、沒有分析工具、沒有追蹤器、不需要帳號。你的出生資料、星盤和日記只儲存在你的裝置上，你可以在應用程式內匯出或刪除。

常見問題

什麼是比較盤（合盤）？

透過一個人的行星與另一人的行星之間形成的相位，來比較兩張本命盤。

需要兩個人的出生時間嗎？

星座和行星之間的相位只需出生日期就能計算。上升星座和宮位疊加則需要兩個人精確的出生時間與地點。

是免費的嗎？
