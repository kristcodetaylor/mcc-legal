今日行星：月亮與行星此刻在哪裡

行星一直在移動：月亮每兩到三天換一次星座，水星每年大約逆行三次。這個頁面在你的瀏覽器中計算此刻的天空，使用的是 My Cosmic Code 應用程式在你手機上所用的同一套天文計算。

今日行星：星座、月相與逆行

太陽、月亮與各行星此刻的位置：月相與月亮星座、每顆行星的星座與度數、哪些行星正在逆行，以及未來 7 天的變化。

計算器會顯示什麼

  • 月相、月亮被照亮的比例、月亮的星座與度數，以及它何時進入下一個星座。
  • 太陽、月亮與八顆行星，各自的星座與度數。
  • 目前有哪些行星逆行：從地球看，它們的視運動正在倒退。
  • 未來 7 天：新月、滿月與上下弦月、換星座的行星，以及轉為逆行或順行的行星。

水星逆行了嗎？

看逆行那一行：如果水星帶著 ℞ 出現在那裡，它此刻就在逆行。從地球看，行星有一段時間看起來在黃道上倒退，這就是逆行。它並沒有真的掉頭；這是因為地球和那顆行星以不同的速度運行。行星轉向的那一天稱為「留」，會出現在未來 7 天的清單中。

在應用程式中

  • 行星：同一片天空，加上今天各行星之間的相位，還能一天一天查看任何一天的天空。
  • 宇宙即時：今天的天空觸及你本命盤的哪些地方，附上月亮與你的個人日。
  • 宇宙時間軸：你的星盤即將到來、標有日期的事件。
  • 行運通知：行星轉為逆行或順行、新月或滿月、行星進入你的星座。每週最多三則。

常見問題

今天月亮在什麼星座？

計算器在最上方顯示，附上度數與進入下一個星座的時間。月亮每兩到三天換一次星座，所以答案在一天之內也可能改變。

目前哪些行星在逆行？

計算器會列出來。水星每年大約逆行三次，每次約三週；金星和火星較少；木星到冥王星每年都會逆行好幾個月。太陽和月亮從不逆行。

時間是哪個時區？

你瀏覽器的時區。選擇一個城市，就能看到當地的時間。行星位置在地球上任何地方都一樣，改變的只有時鐘上的時間。

準確度如何？

位置依真實的天文計算得出，誤差小於一角分。月相與換星座精確到分鐘；「留」只精確到日，因為行星在那前後幾乎靜止不動。

會傳送任何資料嗎？

不會。一切都在你的瀏覽器中計算，不會儲存也不會傳送。應用程式在你的手機上也是這樣運作。
