星圖：你頭頂上的真實星空，今晚或你出生的那一天

把手機舉向天空，就能看到頭頂上有什麼：恆星、星座、月亮與行星，任何地點、任何時刻都可以。My Cosmic Code 在你的手機上依真實天文資料計算星空；在「我的宇宙星空」裡，還會把你出生時的行星放進星空之中。

你會看到什麼

  • 肉眼可見的每一顆恆星（亮到 5.5 等），以及全部 88 個星座的連線，標示國際通用的拉丁名稱。
  • 太陽、月亮與行星的真實位置：離地平線多高、在哪個方向，以及何時升起、何時落下。
  • 深空天體：42 個星系、星雲與星團，包括仙女座星系、獵戶座大星雲與昴星團。
  • 搜尋行星或恆星，點一下天空中的任何天體即可看到詳細資料。

頭頂上，或任何地方

  • 「對準天空」：把手機舉起來，星圖就會跟著轉動。使用的是指南針，不是相機。
  • 「目前位置」：你所在之處的天空。只使用大略位置，只在你點按時才詢問，而且從不儲存或傳送。
  • 「今晚」：白天時點一下，就會跳到該地點下一次天黑的時刻，也就是太陽沉到地平線下夠深、星星看得見的時候。
  • 任何城市、任何時刻：一次前進或後退一小時或一天，再點「現在」回來。
  • 每個地方都看到自己的天空：從雪梨或布宜諾斯艾利斯，看到的是南半球的星空。

你出生時的星空，以及「我的宇宙星空」

  • 「我出生時的星空」：你出生那一刻，出生地上空的真實星空。
  • 「我的宇宙星空」：你出生時的行星以金色圓環標在黃道上，位置就是你出生時它們所在之處；今天的行星則在星星之間從它們旁邊經過。
  • 今天的行星與你出生時行星之間的相位，以線條畫出。
  • 兩種檢視清楚分開：真實天空呈現天上實際有什麼；「我的宇宙星空」則把你的本命盤疊加上去，並清楚標明。

隱私優先的設計

沒有廣告、沒有分析工具、沒有追蹤器、不需要帳號。你的出生資料、星盤和日記只儲存在你的裝置上，你可以在應用程式內匯出或刪除。

常見問題

今晚看得到哪些行星？

點「目前位置」。如果天還亮著，再點「今晚」，星圖會跳到你那裡下一次天黑的時刻。你會看到地平線上方的行星、它們的高度與方向；點一下行星，就能看到它升起與落下的時間。

可以看我出生那天的星空嗎？

可以。「我出生時的星空」會顯示你出生那一刻、出生地上空的真實星空。需要你的出生日期與出生地點；有出生時間就是那一分鐘，沒有的話應用程式會以中午計算。

會用到相機或我的精確位置嗎？

不會。「對準天空」透過指南針與動作感測器跟著手機轉動。「目前位置」只在你點按時詢問大略位置，只用來畫出天空，從不儲存或傳送。你也可以改選一個城市。

這是天文還是占星？

真實天空是天文：恆星、月亮與行星的位置。「我的宇宙星空」把你的本命盤畫在這片天空上，顯示位置與相位；不會替星星本身賦予任何意義。
